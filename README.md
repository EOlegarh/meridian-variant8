## Запуск

Python 3.12 или новее. На обычном Linux:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
DJANGO_DEBUG=1 python manage.py runserver 127.0.0.1:8008 --insecure
```

Открыть http://127.0.0.1:8008. Команда seed_demo предназначена для пустой базы: создаёт пользователей, 12 направлений и туров, 36 заездов и 36 бронирований. Даты новых заездов отсчитываются от дня заполнения. Повторный запуск заполненной базы не нужен.

На NixOS сначала выполните `nix-shell` в каталоге проекта, затем те же команды внутри `.venv`. shell.nix подключает zlib для Pillow. Секрет и режим отладки можно задать переменными из .env.example; файл .env сам по себе автоматически не читается. Для локальной демонстрации предусмотрен резервный ключ. При публикации задайте отдельный DJANGO_SECRET_KEY и настройте хосты, статику, почту и HTTPS.

## Учебные аккаунты

Общий пароль: `DemoTravel8!2026`.

| Логин | Роль |
| --- | --- |
| tourist01 … tourist12 | Турист |
| manager | Менеджер |
| admin | Администратор |

Турист видит свои брони, меняет состав до оплаты, отменяет неоплаченную поездку и оставляет отзыв после её завершения. Менеджер смотрит бронирования, заезды и аналитику, регистрирует оплату и выгружает CSV. Администратор дополнительно управляет турами и заездами. Чужая бронь отвечает 403.

Запись платежа учебная: банковское списание не выполняется. Письма о брони и обращения отправляются через консольный почтовый модуль. Автоматический возврат оплаченной брони не подключён. Цена фиксируется в бронировании; изменение состава до оплаты вызывает новый расчёт.

## Проверки

```sh
python manage.py check
python manage.py test travel
python tools/export_pages.py
```

`tools/package.json` фиксирует зависимости Playwright и Lighthouse. Установка: `cd tools && npm ci`, затем вернуться в корень проекта. Для браузерных проверок нужен Chromium; при необходимости установить браузер командой `npx playwright install chromium` из tools. Скрипты используют системный Chromium NixOS, когда он доступен. Для иных систем Lighthouse использует Chrome из chrome-launcher; можно задать CHROME_PATH.

```sh
node tools/browser_check.mjs
node tools/lighthouse_check.mjs home tours booking_new
python tools/validate.py
python tools/quality_summary.py
```

Сайт должен работать на 127.0.0.1:8008. Для снимков собственных страниц 403/404 запустите его с DJANGO_DEBUG=0 и `--insecure`. Проверяются ширины 360, 375, 768, 1024 и 1440 px, сохраняются скриншоты 375 и 1440 px. Официальный HTML-сервис ограничивает частоту запросов; для продолжения предусмотрен tools/retry_html.py. Отчёты содержат результаты локальной демонстрационной базы, а не оценку развёртывания на внешнем сервере.

Фотографии взяты из макета работы 6. Авторы, ссылки и лицензии перечислены на странице контактов и в static/images/sources.json. Шрифты Noto распространяются по OFL, текст лицензии находится в static/fonts/LICENSE.txt.
